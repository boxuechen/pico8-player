# Phase 4 reviewed benchmark evidence

This directory separates disposable smoke output from reviewed evidence:

- `results/*-smoke.json` is generated by ordinary Node/Chrome test commands and is gitignored.
- `results/chromium-macos-arm64-l2-baseline.json` and
  `results/node-macos-arm64-l2-baseline.json` are the reviewed Phase 4B baseline.
- `results/chromium-macos-arm64-phase-4g-long-run.json` is the reviewed 1800-second
  Chrome resource/lifecycle run. Reproduce it explicitly with `pnpm run evidence:phase-4g`.

The long-run artifact contains two heap signals. `performance.memory` samples describe the whole
page process and remain diagnostic because Worker isolates and collection timing create a sawtooth.
The hard retained-heap gate uses Chrome DevTools Protocol garbage collection and heap usage for the
main page isolate at controlled before/after checkpoints. Ordinary `pnpm run verify` hash-locks and
validates the reviewed artifact; it runs the short Chrome smoke gate instead of repeating 30 minutes.
