# Active phase documents

Phase documents are the executable entry point for current development. Each
one owns its phase scope, stable inputs, work breakdown, file boundaries,
acceptance evidence and exit gate. Roadmap summaries belong in
[`05-delivery-plan.md`](../05-delivery-plan.md); implementation details do not.

The active phase is
[`Phase 1: L1 minimal playable loop`](./1-l1-minimal-playable-loop.md). Phase 1A–1D
are complete and Phase 1 remains active for work unit 1E. Phase 0F's
execution record is archived as
[`17-phase-0f-evidence.md`](../evidence/phase-0/17-phase-0f-evidence.md).

Only one phase may be current at a time. Completed phase documents move
to `docs/evidence/` with their immutable evidence; future phases remain compact
roadmap entries until they become active.
