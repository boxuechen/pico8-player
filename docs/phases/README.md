# Active phase documents

Phase documents are the executable entry point for current development. Each
one owns its phase scope, stable inputs, work breakdown, file boundaries,
acceptance evidence and exit gate. Roadmap summaries belong in
[`05-delivery-plan.md`](../05-delivery-plan.md); implementation details do not.

There is currently no active phase. [`Phase 1: L1 minimal playable
loop`](./1-l1-minimal-playable-loop.md) is complete through 1F and is retained as
the execution record; its exit evidence is
[`21-phase-1-l1-exit-evidence.md`](../evidence/phase-1/21-phase-1-l1-exit-evidence.md).
The next task must create and activate a separate Phase 2 document before
production implementation. Phase 0F's execution record is archived as
[`17-phase-0f-evidence.md`](../evidence/phase-0/17-phase-0f-evidence.md).

Only one phase may be current at a time. Completed phase evidence is immutable;
future phases remain compact roadmap entries until they become active.
